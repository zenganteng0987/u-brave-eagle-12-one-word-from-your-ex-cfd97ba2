This entry is a tiny Node program for make.fun's "One Word From Your Ex" bounty ($2): it writes exactly one word — "exhausting" — the word an ex would use to describe the entrant, to /output/entry.txt. It is funny because it reframes the whole relationship as tiring work, it stings because it is painfully true and plainly self-aware, and it lands instantly with no explanation needed.

## Run it

```sh
node main.ts
```
